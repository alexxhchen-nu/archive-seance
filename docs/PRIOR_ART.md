# Prior art and provenance

This file records where the code in this repository comes from. It is based on the author's own statements, made on 2026-11-21.

## Code written in the contest window

- Every line of code in this repository was written on or after **2026-10-30**. The git history is the evidence: the first commit is dated 2026-11-21.
- The project reuses **no code from earlier projects**. There are **no exceptions**.

## No external references

- No external papers, preprints, or projects were used as references for the design or the code.
- The author has a preprint of their own on Zenodo (author: Chen, Xiaohan). It is **not** used as a reference or as a source of ideas for this project. It is named here only so a reader who finds it knows it is unrelated to this work.

## Third-party libraries

The project depends on open-source libraries that it imports and bundles or uses for development. They are the only outside code in the application. Names, uses, and licenses are in [`THIRD_PARTY.md`](../THIRD_PARTY.md); exact versions are pinned in `package.json` and `package-lock.json`.

- Shipped in the extension build: `firebase` (Firebase AI Logic, App Check) and `pdfjs-dist` (PDF parsing, with its worker bundled locally). `d3` is pinned for the graph view and is not imported yet.
- Development only: TypeScript, Vite, Vitest, fast-check, ESLint (with `typescript-eslint`, `@eslint/js`, `globals`), jsdom, Playwright.

## Other third-party material in the repository

- `.agents/skills/chrome-extensions` and `.agents/skills/modern-web-guidance` are agent guidance documents (Markdown) copied from [GoogleChrome/modern-web-guidance](https://github.com/GoogleChrome/modern-web-guidance) at commit `64a6d708f5a43f2cd3fde5d4d7db3905ba1bdf65` (see `skills-lock.json`). They are instructions for coding agents, not application code, and they are not shipped in the extension. They remain under their upstream license; this repository's Apache-2.0 `LICENSE` does not relicense them.
- The demo PDFs named in [`DEMO_SOURCES.md`](./DEMO_SOURCES.md) are US federal government works in the public domain. They are not committed. Test fixtures under `test/fixtures/` are synthetic, with made-up text generated by `scripts/make-fixtures.mjs`.
